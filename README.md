# Task 3 - Infrastructure as Code with Terraform

## Objective

Provision a local Docker container using Terraform.

## Tools Used

- Terraform
- Docker
- Nginx

## What I Did

1. Installed Terraform.
2. Installed and configured Docker.
3. Created a Terraform configuration using the Docker provider.
4. Created an Nginx Docker image using Terraform.
5. Created an Nginx Docker container using Terraform.
6. Used terraform init.
7. Used terraform validate.
8. Used terraform plan.
9. Used terraform apply.
10. Checked Terraform state.
11. Tested the Nginx container.
12. Used terraform destroy to remove the infrastructure.

## Terraform Commands

```bash
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform state list
terraform show
terraform destroy
